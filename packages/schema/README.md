# @goodboy/schema

The canonical GoodBoy skill manifest schema and generated type definitions.

## Schema

The manifest schema lives in `src/manifest.schema.json`. It is a JSON Schema draft-07 document that defines the shape of a `goodboy.json` skill manifest file.

## Versions

Immutable snapshots of each published schema version are stored under `versions/<version>/manifest.schema.json`. Once a version is published it is never modified.

## Generated Types

TypeScript type definitions are auto-generated from the schema and written to `generated/ts/index.d.ts`. Do not edit this file by hand — run `npm run generate` to regenerate it.

## Contributing

To update the schema, edit `src/manifest.schema.json`, then run:

```sh
npm run generate
```
